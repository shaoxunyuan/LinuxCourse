Linux 实验1｜第一次进入 Linux08

练习2：用 ls 看“这里有什么”

pwd
ls
ls -l
ls -a
ls -la

含义

  • ls：列出文件和目录
  • ls -l：长格式详细显示
  • ls -a：包含隐藏文件（以 . 开头）

观察

  • 哪条命令信息最多？
  • ls -a 是否多出以 . 开头的项？
  • 主目录里有哪些文件夹？
Linux 区分大小写：ls 与 LS 不是同一条命令。

练习3：在 Linux 目录中“走一圈”

每切换一次目录，都用 pwd 确认当前位置

4–5

6–7

最后执行 cd ~ 与 pwd，应回到 /home/njucm。再自己完成：/ → /home → /tmp → ~。

Linux 实验1｜第一次进入 Linux13

课堂综合练习

  • 确认当前用户、主机名、位置、系统时间和内核信息
  • 依次进入 /、/home、/tmp，每到一处执行 pwd，并用 ls 查看
  • 回到主目录，分别执行 ls、ls -l、ls -a、ls -la
  • 进入 ~/LinuxLab，用 ls -la 检查 data、script、result 和 README.txt
  • 用 man ls 或 ls --help，再确认 -a 与 -l 的含义
完成标准：以上操作连续完成；出错时能用 pwd、ls 和帮助系统自查。
Linux 实验1｜第一次进入 Linux14

常见报错：先看它在说什么

No such file or directory

路径或名字写错 → pwd / ls 检查

command not found

命令写错 → 检查大小写和拼写

Permission denied

当前用户没有权限 → 先确认操作

Is a directory

把目录当普通文件操作 → ls -l 查看对象

排错：看报错 → pwd 看位置 → ls 看内容 → 检查大小写 → 查帮助。
