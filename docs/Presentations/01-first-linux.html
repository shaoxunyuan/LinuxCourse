命令演示：确认“我是谁、在哪、什么时候”

五条环境命令，执行一条看一条输出

命令作用

whoami 当前用户；hostname 主机名；pwd 当前目录；date 日期时间；uname -a 内核与系统信息。

观察要点

用户名是否为 njucm？主目录是否为 /home/njucm？内核信息里能看到什么？

输出与同学不同很正常，先想想主机名、时间和登录用户为什么可能不同。

Linux 实验1｜第一次进入 Linux10

命令演示：用 ls 看“这里有什么”

同一个目录，换参数再看一遍

pwd
ls
ls -l
ls -a
ls -la

参数含义

  • ls：查看当前目录中的文件和目录
  • ls -l：用较详细的长格式显示
  • ls -a：把隐藏文件也显示出来
  • ls -la：长格式并包含隐藏文件

观察任务

  • 哪条命令显示的信息最多？
  • ls -a 后是否多出以 . 开头的项目？
  • 你的主目录里有哪些文件夹？
Linux 区分大小写：ls 与 LS 不是同一条命令。

不会命令时：man、--help 与 Tab 补全

Linux 新手的“救命工具”

man ls
# 按 q 退出 man
ls --help
man mkdir
mkdir --help

man 命令

查看比较完整的手册。练习：man ls。

命令 --help

快速查看常用选项。练习：ls --help。

Tab 补全

输入一部分后按 Tab，减少拼写错误。

自己查

查出 -a、-l 的含义；用 Tab 补全 /ho 后面的路径。

规则：先查帮助；先读报错；再改命令。不要一遇到问题就猜。

命令演示：创建你的第一个 LinuxLab

先完全照着教程敲，确认结构正确

cd ~
mkdir LinuxLab
cd LinuxLab
mkdir data
mkdir script
mkdir result
touch README.txt
pwd
ls -la

最终结构

LinuxLab/
├── data/
├── script/
├── result/
└── README.txt

三个要点

mkdir 创建目录；touch 创建空文件；ls -la 检查目录内容是否创建成功。

常见报错：先看它在说什么

排错习惯：看报错 → 看位置 → 看内容 → 再修改

No such file or directory

路径或名字写错。用 pwd / ls 检查当前位置和拼写。

command not found

命令写错或不存在。先检查大小写和拼写。

Permission denied

当前用户没有权限。先确认操作，不要一看到就 sudo。

Is a directory

把目录当作普通文件操作。先用 ls -l 看对象是什么。

pwd
ls
ls -l
man ls
