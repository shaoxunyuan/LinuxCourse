cut -d：指定分隔符

让 cut 知道每一列之间用什么字符隔开

cut -d ',' -f 1 scores.csv
cut -d ',' -f 2 scores.csv

-f 1 输出姓名

开头几行：Name、Alice、Bob、Cindy、David、Eva

-f 2 输出成绩

开头几行：Score、88、72、95、60、100

-d 后面只能跟一个字符；英文逗号必须写在引号内。表头也会被输出，它是第 1 行。
Linux 实验7｜文本字段提取与筛选08

cut -f：选择指定字段

-f 1 表示第一列，-f 2 表示第二列

cut -d ',' -f 1,2 scores.csv
cut -d ',' -f 3 scores.csv

-f 1,2 同时输出两列

Name,Score
Alice,88
Bob,72
Cindy,95

-f 3 只输出班级

Class
Class1
Class1
Class2

-f 1,2 的输出仍用逗号连接；连续字段也可写成 -f 1-3。
Linux 实验7｜文本字段提取与筛选09

awk：通过 $1、$2 读取字段

使用 print 输出当前记录中的指定字段

awk -F ',' '{print $1}' scores.csv
awk -F ',' '{print $1, $2}' scores.csv

-F ','

告诉 awk 用逗号分隔字段

$1 与 $2

第一列姓名，第二列成绩

输出格式

print $1, $2 默认用空格连接：Alice 88

$0

当前整行；字段编号从 1 开始

单引号中的 {print $1} 是 awk 程序，$1 表示第一列。
Linux 实验7｜文本字段提取与筛选10

awk -F：为什么必须指定逗号分隔符

CSV 是逗号分隔；awk 默认按空白字符分列

awk '{print $1}' scores.csv
awk -F ',' '{print $1}' scores.csv

不加 -F

整行 CSV 被当作一个字段，输出整行：
Name,Score,Class
Alice,88,Class1

加上 -F ','

按逗号分列，输出第一列：
Name
Alice
Bob

处理逗号分隔的成绩表时，记得设置 -F ','。cut 用 -d，awk 用 -F。
Linux 实验7｜文本字段提取与筛选11

awk：按成绩条件筛选

使用 $2 > 80 判断第二列成绩是否符合条件

awk -F ',' '$2 > 80 {print $1, $2}' scores.csv

表达式含义

$2 > 80：成绩大于 80；{print $1, $2}：输出姓名和成绩。

真实现象

输出第一行是 Name Score，因为表头没有被排除；后面才是符合条件的学生。

这就是下一张要用 NR>1 跳过表头的原因。
Linux 实验7｜文本字段提取与筛选12

NR>1：排除表头再筛选

NR 是当前行号，NR>1 表示从第 2 行开始处理

awk -F ',' 'NR>1 && $2 > 80 {print $1, $2}' scores.csv
awk -F ',' 'NR>1 && $2 >= 90 {print $1, $2}' scores.csv

> 80：共 13 行

开头为 Alice 88、Cindy 95、Eva 100、Frank 88、Kevin 83……

>= 90：共 7 行

Cindy 95、Eva 100、Lily 91、Peter 100、Victor 90、Zoe 96、Cindy 95

&& 表示两个条件同时满足；原文件保持不变。
