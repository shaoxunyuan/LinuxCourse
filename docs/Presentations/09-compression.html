打包与压缩不是一回事

先理解两个动作的区别，再记命令

打包（tar）

  • 把多个文件或目录合并成一个归档文件
  • 便于整体保存、复制和传输
  • 不承诺减小体积

压缩（gzip / zip）

  • 用压缩算法减少数据体积
  • 生成 .gz 或 .zip 文件
  • 可与打包组合为 .tar.gz
.tar 只是归档包；.tar.gz 才是“打包 + 压缩”。
记忆顺序：先打包，再压缩；恢复时先解压，再解包。
Linux 实验9｜文件压缩与解压05

tar 的常用选项

选项决定 tar 是创建、查看、解包还是压缩

-c

创建新的归档文件

-x

从归档文件中提取内容

-t

列出归档中的文件清单

-v

显示处理过程

-f

指定归档文件名，必须紧跟文件名

-z

调用 gzip 压缩或解压

常用组合：-cvf 创建　-tvf 查看　-xvf 解包　-czvf 压缩　-xzvf 解压

tar -cvf：创建归档文件

将整个目录打包为一个 .tar 文件

tar -cvf ArchiveLab.tar ArchiveLab/
tar -tvf ArchiveLab.tar

创建归档

-c 创建归档；-v 显示过程；-f 指定归档文件名。

查看归档

-t 列出归档中的文件，不会解压或修改原始目录。

tar 文件完成了打包，但不代表已经进行了压缩。
Linux 实验9｜文件压缩与解压09

先查看归档：tar -tvf

解压之前，先确认归档里到底有什么

tar -tvf ArchiveLab.tar

文件清单

逐行列出归档中的文件和目录

不解压

只读取归档，不生成新文件

不改原始目录

源目录保持原样

核对完整性

确认需要的文件都已被打包

解压前先看清单，能避免把不需要的文件覆盖到当前目录。
Linux 实验9｜文件压缩与解压10

tar -xvf：解开归档文件

将 .tar 文件中的内容恢复到目录

mkdir -p restore_tar
tar -xvf ArchiveLab.tar -C restore_tar
find restore_tar -type f

-x

表示从归档文件中提取内容。

-C 目录

指定解压目标目录，把恢复结果与原始文件分开比较。

不指定 -C 时，文件会解压到当前目录，可能覆盖同名文件。
Linux 实验9｜文件压缩与解压11

tar -czvf：创建 tar.gz 压缩包

在打包的同时使用 gzip 压缩

tar -czvf ArchiveLab.tar.gz ArchiveLab/
ls -lh ArchiveLab.tar ArchiveLab.tar.gz

-z

调用 gzip 对归档数据进行压缩，常见扩展名为 .tar.gz 或 .tgz。

比较文件大小

用 ls -lh 比较 .tar 与 .tar.gz 的大小，压缩效果与文件内容有关。

tar -czvf = 创建归档 + gzip 压缩；原始目录仍然保留。
Linux 实验9｜文件压缩与解压12

tar -xzvf：解压 tar.gz

将压缩归档恢复为文件和目录

mkdir -p restore_gz
tar -xzvf ArchiveLab.tar.gz -C restore_gz
find restore_gz -type f

-x 与 -z

-x 提取归档；-z 通过 gzip 解压。

-C

指定恢复文件的目标目录，避免覆盖当前目录内容。

解压完成后，检查目录结构和文件数量是否与原始内容一致。
Linux 实验9｜文件压缩与解压13

gzip 与 gunzip

处理单个文件的 .gz 压缩格式

gzip -k ArchiveLab/README.txt
ls -lh ArchiveLab/README.txt*
gunzip ArchiveLab/README.txt.gz

gzip

压缩单个文件，通常生成 .gz；默认会用 .gz 替代原文件，-k 可保留原文件。

gunzip

解压 .gz 文件，恢复原始文件。

gzip 只处理单个文件；要压缩整个目录，应先用 tar 打包。
Linux 实验9｜文件压缩与解压14

zip 与 unzip：跨平台的压缩格式

创建 ZIP 包，查看内容并解压到指定目录

zip -r ArchiveLab.zip ArchiveLab/
unzip -l ArchiveLab.zip
mkdir -p restore_zip
unzip ArchiveLab.zip -d restore_zip

创建与查看

  • zip -r：递归压缩目录及其内容
  • unzip -l：只查看 ZIP 包中的文件列表

解压

unzip -d 指定解压目标目录，恢复结果不会散落在当前目录。

ZIP 对 Windows 用户很熟悉；Linux 项目中 tar.gz 也非常常见。

常见问题：先检查路径与压缩格式

tar: Cannot open

检查当前目录、归档文件名和权限，用 pwd、ls 确认文件位置。

解压后找不到文件

检查是否指定了 -C 或 -d 目标目录，并查看解压时的完整路径。

gzip 后原文件不见了

gzip 默认生成 .gz 并替代原文件；需要保留原文件时使用 gzip -k。

ZIP 包中缺少子目录

压缩目录时使用 zip -r，确保递归包含目录中的文件。

排错顺序：检查路径 → 检查文件名与格式 → 检查选项 → 查看解压目录。
