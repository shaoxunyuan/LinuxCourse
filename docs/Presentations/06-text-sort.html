Linux 实验6｜文本排序与去重05

概念讲解：sort -r 与 sort -n

一个反转顺序，一个按数值大小比较

逆序排序

sort -r scores.txt

在相同比较规则下，将排序结果反向输出。

数值排序

sort -n scores.txt

按数字大小比较，而不是按字符逐个比较。

printf "9\n18\n100\n" | sort
printf "9\n18\n100\n" | sort -n
普通 sort 得到 100、18、9；sort -n 得到 9、18、100。数字的文本顺序与数值大小可能不同。
Linux 实验6｜文本排序与去重06

概念讲解：sort -k 指定排序字段

scores.txt 每行是“姓名 成绩”两列，按成绩排序要用第 2 列

sort -k2,2n scores.txt
sort -k2,2nr scores.txt

第 1 列

姓名，例如 Alice

第 2 列

成绩，例如 88

选项组合

-k2,2 以第 2 列为排序键
n 按数值
r 反向

按成绩升序用 sort -k2,2n；按成绩降序用 sort -k2,2nr。
Linux 实验6｜文本排序与去重07

概念讲解：uniq 处理相邻重复行

uniq 默认只合并相邻且完全相同的记录

uniq scores.txt
sort scores.txt | uniq

重点区别

  • sort：调整记录顺序
  • uniq：把连续出现的相同完整记录合并为一条
  • 分散在文件不同位置的相同记录可能仍被保留
uniq 不是“全文件自动去重”；处理无序数据时先排序更稳妥。
Linux 实验6｜文本排序与去重08

概念讲解：uniq 常用选项与管道

在去重基础上统计和筛选重复记录

uniq

相邻相同记录只保留一条

uniq -c

显示每组相邻相同记录的次数

uniq -d

只显示重复出现的记录

uniq -u

只显示只出现一次的记录

sort scores.txt | uniq
sort scores.txt | uniq -c
sort scores.txt | uniq -d
sort scores.txt | uniq -u
管道符 | 将左侧 sort 的输出传递给右侧 uniq。

Linux 实验6｜文本排序与去重13

命令演示：uniq 与 sort | uniq

uniq scores.txt
sort scores.txt | uniq

直接 uniq

只合并相邻的完全相同记录；被其他行隔开的重复记录仍保留。

sort | uniq

先把相同记录排到一起，再去重，得到 26 种不同记录。

原文件行数

scores.txt 共 40 行

去重后行数

40 → 26，说明有 14 行是重复记录

为什么先 sort 会改变结果？因为 uniq 只能合并相邻的完全相同行。
Linux 实验6｜文本排序与去重14

命令演示：uniq -c / -d / -u

sort scores.txt | uniq -c
sort scores.txt | uniq -d
sort scores.txt | uniq -u

uniq -c

共 26 组；例如 5 Bob 72、4 Alice 88，数字表示该整行记录出现次数。

uniq -d

输出出现至少两次的记录，每种一次，共 9 种。

uniq -u

输出只出现一次的记录，共 17 种。

uniq -c 统计的是每种完整记录出现的次数，不是仅统计某个姓名出现几次。
