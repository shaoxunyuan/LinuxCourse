sort 默认排序与 sort -r 逆序

-r 反转排序顺序，但不保证就是分数从高到低

默认排序

sort scores.txt

按区域规则正序排列。

逆序排序

sort -r scores.txt

反转上述排序顺序。

观察：两次输出的第一行和最后一行有什么不同？-r 反转的是排序顺序，并不保证分数从高到低。

sort -n：按数值大小排序

默认按字符规则排序，"100" 会排在 "85" 前面

字符排序（默认 sort）：按字典序比较每行开头

数值排序（sort -n）：按第一列整数大小

sort -n scores.txt
本实验第一列是分数，因此 sort -n 可以按第一列的数字从小到大排序。当想按数值大小排序时，使用 -n。
Linux 实验6｜文本排序与去重09

sort -k：按指定字段排序

-k 指定以第几列为排序键，便于按姓名或按成绩排序

sort -k2,2 scores.txt
sort -k2,2r scores.txt

列号示意

  • 第一列：成绩（如 85）
  • 第二列：姓名代号（如 ZhangWei）
  • -k2,2：主要按第二列作为排序键
  • 末尾 r：在该键上逆序
此处只学习按字段排序，不讨论复杂多关键字规则。

记住四个最常用的排序方式

解释：以第一列的数值为排序键，按从大到小排列。
Linux 实验6｜文本排序与去重11

uniq：检查相邻重复行

uniq 只合并连续相邻、内容完全相同的行

uniq [选项] 文件
uniq scores.txt

必须强调

  • 只合并连续相邻、内容完全相同的行
  • 若两条相同记录被其他行隔开，不会合并
  • 比较的是整行内容，不是某一列
uniq 只处理相邻的整行重复；被隔开的重複记录它“看不见”。

Linux 实验6｜文本排序与去重13

uniq -c：统计每条记录出现次数

在每条记录前显示该整行记录出现的次数

sort scores.txt | uniq -c

输出结构

每行前面显示该条完全相同记录出现的次数；例如 3 85 ZhangWei 表示原文件中 85 ZhangWei 这条整行记录共出现 3 次（此为解释样例，不代表配套文件固定结果）。

注意：-c 统计的是相邻完全相同整行的次数，不是仅统计某个姓名出现几次。
Linux 实验6｜文本排序与去重14

uniq -d 与 uniq -u

一个只看重复记录，一个只看唯一记录

-d 只输出重复记录

sort scores.txt | uniq -d

只输出出现至少两次的记录，每种记录输出一次。

-u 只输出唯一记录

sort scores.txt | uniq -u

只输出恰好出现一次的记录。

思考：-d 和 -u 是否可以互相代替？它们分别回答“哪些重复”和“哪些没重复”。
Linux 实验6｜文本排序与去重15

排序、去重与统计的组合

把 sort、uniq、wc 串起来，回答不同层面的问题

sort scores.txt | uniq
sort scores.txt | uniq -c
sort scores.txt | uniq | wc -l

查看不同记录

第一条：去掉相邻重复，列出所有不同整行记录。

统计每种次数

第二条：显示每种记录各出现多少次。

统计记录种数

第三条：不同整行记录一共有多少种。

区别

wc -l scores.txt 是总行数；sort | uniq | wc -l 是不同记录种数，通常不同。
