Linux 实验5｜文本搜索与统计05

概念讲解：grep -i 与 grep -n

一个忽略大小写，一个显示原文件行号

不加 -i

grep "error" app.log

只匹配小写 error，对大小写敏感。

加上 -i

grep -i "error" app.log

忽略大小写，匹配不同写法的 error 记录。

显示行号

grep -n "ERROR" app.log

在结果前增加原文件中的行号，例如 3:...。

组合选项

grep -in "error" app.log

-in 与 -i -n 效果相同。

-i 只改变匹配时的大小写规则，不改变原始文件内容。
Linux 实验5｜文本搜索与统计06

概念讲解：grep -v 反向筛选

显示不匹配指定模式的行

正向搜索

grep "INFO" app.log

保留包含 INFO 的行。

反向筛选

grep -v "INFO" app.log

保留不包含 INFO 的行。

组合选项

grep -iv "error" app.log

先忽略大小写，再排除所有 error 行。

-v 表示反向选择，常用于排除无关记录。筛选前后可对照原文件确认。

概念讲解：wc -l 与管道符 |

wc 是统计命令，-l 表示统计换行符的数量

grep 命令
grep -i "error" app.log
|
wc -l
统计行数
=
匹配行数
wc -l app.log
cat app.log | wc -l
grep -i "error" app.log | wc -l
管道把左边命令的标准输出交给右边命令继续处理；它连接的是命令的输出和输入，并不修改文件。

常见问题：先检查命令和文件

grep: app.log: No such file

路径或文件名不正确。先用 pwd、ls 确认文件是否存在。

grep 搜索后没有输出

可能没有匹配行，也可能大小写不一致；尝试 -i。

wc: invalid option

选项书写错误。检查是否把 -l 写成了 -1。

管道没有得到预期数量

检查管道两侧命令、引号与关键词是否正确。

排错顺序：检查位置 → 检查文件 → 检查关键词和选项 → 再运行验证。
