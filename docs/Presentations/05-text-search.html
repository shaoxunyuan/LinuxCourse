Linux 实验5｜文本搜索与统计09

grep -n：显示行号

搜索结果前增加原文件中的行号

grep -n "ERROR" app.log
grep -in "error" app.log

阅读结果

例如 2:ERROR Disk full 中，2 表示原文件第 2 行。

组合选项

-i 与 -n 可合用；-in 等价于 -i -n。

行号便于在日志与配置文件中快速定位。

grep -v：反向筛选

显示不匹配指定模式的行

正向搜索

grep "INFO" app.log

保留匹配的行

反向筛选

grep -v "INFO" app.log

保留不匹配的行

组合选项

grep -iv "error" app.log

先忽略大小写，再排除

思考

上述命令各输出多少行？为何保留这些行？

结论：-v 表示反向选择。

wc -l：统计行数

wc 是统计命令，-l 表示统计换行符的数量

直接统计文件

显示计数，并附带文件名。

管道统计

统计管道收到的行，通常只显示数字。

文件末尾应有换行；具体结果以实际文件为准。
Linux 实验5｜文本搜索与统计12

认识管道符 |

把左边命令的标准输出交给右边命令继续处理

grep 命令
grep -i "error" app.log
|
wc -l
统计行数
=
匹配行数

grep 先输出匹配的日志行，wc -l 接收这些行并统计数量。管道不修改文件。

常用组合：grep … | wc -l → 符合条件的行有多少。
