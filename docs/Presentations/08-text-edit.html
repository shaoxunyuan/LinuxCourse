sed -n 与 p：显示指定行

使用 -n 关闭默认输出，再用 p 指定要显示的行

sed -n '1,5p' scores.csv
sed -n '8p' scores.csv

按行号范围显示

'1,5p' 输出前 5 行：Name,Score,Class、Alice,88,Class1、Bob,72,Class1、Cindy,95,Class2、David,60,Class2

只显示第 8 行

输出 Grace,45,Class2

-n 与 p 常配合使用，避免默认输出导致内容重复显示。

sed -n 与 p：按关键词筛选

把模式写在斜杠之间，只打印匹配行

sed -n '/Class3/p' scores.csv

输出结果：共 8 行

Eva,100,Class3、Henry,9,Class3、Kevin,83,Class3、Nina,67,Class3、Queen,42,Class3、Tina,65,Class3、Wendy,77,Class3、Zoe,96,Class3

读法

/Class3/ 是匹配模式，p 表示打印；配合 -n 只输出匹配行。

可把关键词换成 Class2 再试一次，观察匹配行数变化。

Linux 实验8｜文本编辑与替换10

sed 's/旧/新/g'：替换全部匹配

g 表示对每一行中的所有匹配位置进行替换

sed -n '26p' scores.csv | sed 's/a/A/'
sed -n '26p' scores.csv | sed 's/a/A/g'

不加 g

只替换第一个 a：
YAra,69,Class2

加上 g

替换所有 a：
YArA,69,ClAss2

g 是 global；一行中有多个匹配时，差别最明显。原文件仍不会被修改。
Linux 实验8｜文本编辑与替换11

sed 的 d：删除与排除匹配行

删除的是输出结果中的行，不会自动修改原文件

sed '/Class3/d' scores.csv
sed '3d' scores.csv

按关键词排除

/Class3/d 排除 8 行 Class3 记录，剩余 23 行输出。

按行号排除

3d 删除第 3 行 Bob,72,Class1，输出其余 30 行。

未使用 -i 时，d 只作用于显示结果，原文件不会被改写。
Linux 实验8｜文本编辑与替换12

sed -i：真正修改文件并做好备份

以配置文件 ~/LinuxProject/config/hospital.conf 为例

方式一：先手动备份

cp hospital.conf hospital.conf.bak
sed -i 's/log_level=INFO/log_level=DEBUG/' hospital.conf

修改后 grep log_level hospital.conf 输出 log_level=DEBUG；备份中仍是 INFO。

方式二：自动生成备份

sed -i.bak 's/log_level=INFO/log_level=DEBUG/' hospital.conf

生成 hospital.conf.bak，原文件被原地修改。

-i 会直接改写文件：务必先备份，再用 cat 或 grep 验证结果。

管道组合：让 sed 参与命令链

管道符 | 把前一条命令的输出交给 sed 继续处理

sed -n '/Class3/p' scores.csv | wc -l
sed 's/Class/Group/g' scores.csv | head -n 3

统计匹配行

第一条命令输出 8，表示 Class3 共 8 行。

只看前 3 行

输出 Name,Score,Group、Alice,88,Group1、Bob,72,Group1。

常见组合：先筛选、再替换、最后统计；管道不修改原文件。

Vim / Nano 最小操作

  • Esc 返回普通模式
  • :wq 保存退出，:q! 放弃

常见问题：先检查命令与匹配规则

sed: can't read ...

检查当前目录和文件名，用 pwd、ls 确认文件存在

替换后没有变化

查找内容需与文件完全一致，注意大小写和空格

输出内容重复

检查是否使用 -n；-n 关闭默认输出，需配合 p

原文件没有变化

未使用 -i 时只改变终端输出，不会改写原文件

排错顺序：检查路径与文件 → 检查匹配内容 → 检查选项 → 再次验证。
