Linux 目录从哪里开始？

整个文件系统从根目录 / 开始，用户主目录在 /home 下

pwd
cd ~
pwd
ls
ls -a

目录层级

/ 是整个 Linux 文件系统的起点；/home 存放普通用户主目录；/home/njucm 就是你的主目录。

/
└── home/
    └── njucm/
        └── LinuxProject/
            ├── data/
            ├── scripts/
            └── results/

记住

主目录通常写成 /home/njucm，也可以简写为 ~。回到主目录用 cd ~。

Linux 实验2｜文件与目录管理05

路径基础：绝对路径、相对路径与常用符号

文件操作是否成功，很多时候取决于路径是否写对

绝对路径

从根目录 / 开始写完整位置，例如 /home/njucm/LinuxProject/data/raw。不受当前所在目录影响。

相对路径

从当前目录出发描述目标位置。若当前在 /home/njucm，可写 LinuxProject/data/raw。更短，但依赖当前位置。

~

当前用户主目录

.

当前目录

..

上一级目录

/

根目录

cd /home/njucm
pwd
cd ..
pwd
cd njucm
pwd
不确定当前位置时先执行 pwd；不确定文件是否存在时先执行 ls。

Linux 实验2｜文件与目录管理10

命令演示：复制文件与目录

cp 的关键是分清“源”与“目标”，复制后原文件仍然保留

cd ~/LinuxProject
cp sample1.txt backup/
cp -i README.txt backup/README_copy.txt
cp -r data backup/data_copy
ls -R backup/

基本格式

cp 源 目标；目标是目录时，文件会复制到该目录中。

cp -i

目标已存在时先询问，避免无意覆盖。

cp -r

复制目录必须递归，连同子目录一起复制。

验证

原文件还在吗？backup 中是否出现副本？

命令演示：移动文件与重命名

mv 既能“搬家”，也能“改名字”

cd ~/LinuxProject
mv README.txt README_Linux.txt
mv notes.txt docs/
mv analysis.py plot.py scripts/
mv result1.csv result2.csv results/
ls -R

重命名

源和目标都是文件：mv 旧名 新名。

移动

目标是目录：文件被搬到该目录中。

批量移动

一次可以给多个源文件，最后写目标目录。

注意

mv 不会保留一份“原件”，移动成功后源位置通常就没有它了。

Linux 实验2｜文件与目录管理14

命令演示：安全删除文件与目录

删除命令通常没有 Windows 式“回收站”，所以先确认再执行

cd ~/LinuxProject
pwd
ls -l temp.txt
rm -i temp.txt
mkdir emptydir
rmdir emptydir
ls -l

1 先看位置

用 pwd 确认自己当前在哪个目录。

2 再看对象

用 ls -l temp.txt 确认要删的是哪个文件。

3 最后删除

rm -i 输入 y 后才真正删除。

rmdir 只删除空目录，目录里还有内容时会失败。不要把 rm -rf 当作常规删除方法。

Linux 实验2｜文件与目录管理16

通配符：先验证匹配范围，再批量操作

文件多起来后，通配符能一次匹配多个对象

cd ~/LinuxProject
ls sample*.txt
ls results/*.csv
ls sample?.txt

*.txt

匹配所有以 .txt 结尾的文件。

sample*.txt

匹配 sample 开头、.txt 结尾的文件。

sample?.txt

? 只代表一个字符，例如 sample1.txt。

安全规则

执行 mv、cp 前先用 ls 看一遍；执行 rm 前更要确认匹配结果。

不要凭感觉输入 rm *.xxx。

常见报错：先看它在说什么

排错顺序：读报错 → pwd → ls → 检查路径和拼写 → 再执行

No such file or directory

路径或文件名写错，或目标不存在。先 pwd，再 ls。

cannot stat

cp / mv 找不到源文件。确认源文件是否存在、当前目录是否正确。

Directory not empty

rmdir 不能删除非空目录。先 ls 查看内容。

cannot overwrite directory

目标类型或路径与预期不一致。用 ls -ld 确认谁是文件、谁是目录。

Permission denied

当前用户没有该操作的权限。先确认对象和权限，不要一看到就 sudo。

排错口诀

看报错文字 → 看当前位置 → 看目录内容 → 检查拼写和大小写 → 再改命令。
