路径基础：绝对路径、相对路径与符号

绝对路径

从根目录 / 写完整位置，例如 /home/njucm/LinuxProject/data/raw。不受当前目录影响。

相对路径

从当前目录出发描述目标。写得更短，但依赖当前位置。

~

主目录

.

当前目录

..

上一级目录

/

根目录

练习2：创建文件并查看信息

cd ~/LinuxProject

touch

创建空文件；已存在则更新时间

file

判断文件类型，不只看扩展名

stat

查看大小、权限、时间等属性

练习3：复制文件与目录

cp 要分清“源”与“目标”；复制后原文件仍保留

cd ~/LinuxProject
cp sample1.txt backup/
cp -i README.txt backup/README_copy.txt
cp -r data backup/data_copy
ls -R backup/

验证

原文件还在吗？backup 中是否出现副本？

思考

复制目录为什么要加 -r？cp -i 何时询问？

Linux 实验2｜文件与目录管理08

练习4：移动文件与重命名

mv 既能“搬家”，也能“改名字”

cd ~/LinuxProject
mv README.txt README_Linux.txt
mv notes.txt docs/
mv analysis.py plot.py scripts/
mv result1.csv result2.csv results/
ls -R
mv 不会保留一份“原件”；移动成功后，源位置通常就没有它了。
Linux 实验2｜文件与目录管理09

练习5：安全删除文件与目录

删除通常没有回收站，先确认再执行

cd ~/LinuxProject
pwd
ls -l temp.txt
rm -i temp.txt
mkdir emptydir
rmdir emptydir
ls -l

rmdir

只删除空目录；目录非空会失败

注意

不要把 rm -rf 当作常规删除方法

Linux 实验2｜文件与目录管理10

练习6：用通配符完成批量操作

cd ~/LinuxProject
ls sample*.txt
mv sample*.txt data/raw/
ls data/raw/
ls results/*.csv
cp results/*.csv backup/
ls backup/

*.txt

匹配以 .txt 结尾的文件

sample*.txt

匹配 sample 开头的 txt

sample?.txt

? 只代表一个字符

安全规则

先用 ls 验证匹配范围，再 mv/cp/rm

练习7：用 ls 检查整理结果

ls

快速看名称

ls -l

权限、大小、时间

ls -a

含隐藏文件

ls -lh

大小更易读

ls -lt

按时间排序

ls -R

递归看整个项目

“命令没报错”不等于“结果一定正确”。用 ls -R 确认文件都在预期位置。

常见报错

No such file or directory

路径写错 → pwd + ls

cannot stat

cp/mv 找不到源文件

Directory not empty

rmdir 不能删非空目录

Permission denied

先确认对象与权限

排错：读报错 → pwd → ls → 检查路径拼写 → 再执行。
