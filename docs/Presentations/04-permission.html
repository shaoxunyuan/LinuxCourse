Linux 实验4｜用户、用户组与权限05

读懂 ls -l：权限字符串

-rw-r--r-- 1 njucm njucm 24 demo.txt
# 类型 | owner | group | others

第 1 位

- 普通文件 · d 目录

第 2～4 位

owner 权限，如 rw-

第 5～7 位

group 权限，如 r--

第 8～10 位

others 权限，如 r--

先分成三组三位：owner｜group｜others，再分别读 r、w、x。
Linux 实验4｜用户、用户组与权限06

r、w、x：对文件和目录含义不同

r 读取

文件：可读内容
目录：可列出名称

w 写入

文件：可修改内容
目录：可创建/删除/改名条目

x 执行/进入

文件：可作为程序执行
目录：可进入并访问其中对象

对目录来说，x 表示“可进入/可穿越”，最容易混淆。
Linux 实验4｜用户、用户组与权限07

chmod 符号法

chmod u+x run.sh
chmod g-w report.txt
chmod o-r secret.txt
chmod a+r README.txt
chmod u=rw file.txt

对象

u / g / o / a

动作

+ 增加 · - 删除 · = 设置

例

u+x：给所有者增加执行权限

修改后立即用 ls -l 验证。符号法适合只改一小部分权限。
Linux 实验4｜用户、用户组与权限08

chmod 数字法：r=4，w=2，x=1

644

自己读写，其他只读

600

只有自己可读写

755

自己可写并执行，其他可读执行

700

只有自己拥有全部权限

chmod 644 file.txt
chmod 600 secret.txt
chmod 755 run.sh
chmod 700 private_dir
不要把 chmod 777 当成“修复权限”的默认做法。

所有者、用户组与 sudo

chown

修改所有者，通常需管理员权限

chgrp

修改所属组

sudo

临时以管理员权限执行；明确需要时才用
