  • 实验1：第一次进入 Linux
    会登录、会认路、会求助 · 终端与基础命令

    从大量文件中找到需要的信息 · cat / less / find

  • 实验7：文本字段提取与筛选

  • 实验9：文件压缩与解压
    把多个文件打包、压缩与恢复 · tar / gzip / zip
  • 实验10：系统信息与进程管理
    找到卡死的程序并处理 · ps / top / kill
  • 实验11：正则表达式
