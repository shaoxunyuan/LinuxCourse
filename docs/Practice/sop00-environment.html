SOP0：认识课程数据与实验环境

在开始敲第一条命令之前，先认识三件事：课在什么环境里上、终端长什么样、本课程的数据放在哪里。本页不要求完成任务，只要求你会启动、会登录、会找到数据。

本课目标 能区分宿主机、虚拟机软件与客户机系统；能登录 CentOS 并打开终端；能找到课程数据文件
项目阶段 准备环境与数据。后续 10 次实验都在同一台虚拟机、同一套练习数据上完成
练习方式 按页面顺序操作，截图留存关键结果，最后按实验报告模板提交到雨课堂

1. 课程环境

本课程不要求你在自己的电脑上安装 Linux，而是使用实验室电脑中的 VMware Workstation 运行课程提供的 CentOS 虚拟机。

宿主机（实验室 Windows 电脑）
        ↓
VMware Workstation（虚拟机软件）
        ↓
CentOS 虚拟机（客户机系统，课程实验环境）
  • 宿主机：实验室里真实存在的 Windows 电脑
  • 虚拟机软件：VMware Workstation，负责运行虚拟电脑
  • 客户机系统：课程提供的 CentOS，所有命令都在这里执行
今天不要修改 CPU、内存、网络、虚拟磁盘设置，也不要移动或删除虚拟机文件。启动失败时先确认选中的是课程虚拟机，再举手说明报错信息。
检查点：能用自己的话说出“宿主机 → VMware → CentOS”的关系。

2. 登录与终端

在 VMware Workstation 中点击 Power on / 启动，等待 CentOS 登录界面出现，然后输入课程统一账号。

Step 1 / 登录信息
用户名：njucm
密码：查看实验电脑 Windows 桌面上的 TXT 文档

# 登录成功后打开 Terminal / 终端
# 后续所有练习都在终端中完成
Step 2 / 认识提示符
[njucm@centos ~]$ whoami
njucm
[njucm@centos ~]$ pwd
/home/njucm
  • njucm：当前登录用户名
  • centos：主机名示意，实际主机名以实验环境为准
  • ~：当前位于自己的主目录 /home/njucm
  • $：普通用户提示符；光标后面才是输入命令的位置
$ 表示普通用户，# 表示 root 用户。提示符本身不是命令，不要把它一起复制进终端。
检查点：能指出提示符中哪部分是用户名、哪部分是当前目录。

4. LinuxProject 练习数据集

为了练习目录、查找、文本处理、权限、压缩和进程，课程提供一个综合数据集。执行脚本后会在桌面生成 LinuxProject/，并建立 ~/LinuxProject 符号链接。

Step 1 / 生成数据
cd ~
bash create_linux_practice_data.sh

# 如果目录已存在，需要重新生成
bash create_linux_practice_data.sh --reset
Step 2 / 目录结构
LinuxProject/
├── README.txt
├── data/
│   ├── patients/          # 模拟患者 CSV
│   ├── labs/              # 模拟检验 CSV
│   └── statistics/        # 科室汇总 CSV 与 summary.json
├── logs/
│   ├── system/            # 系统运行日志
│   ├── application/       # 应用日志与错误日志
│   └── archive/           # 归档日志
├── reports/2024 2025 2026 # 不同年份的报告
├── config/                # hospital.conf / database.conf
├── docs/manuals notes     # Markdown 与短文本
├── archive/backup/        # 不同大小的 .bin 文件
├── tmp/cache/             # 空文件与 .tmp
└── mixed/subdir_A subdir_B # 多级目录与混合类型
数据集刻意包含隐藏文件、空文件、不同大小文件和随机修改时间，方便练习 find 的 -name / -type / -size / -mtime。所有数据均为模拟数据。
检查点：执行 cd ~/LinuxProject && ls，能看到 README.txt 与上述目录。

6. 实验报告与提交

每次实验使用统一实验报告模板，提交到雨课堂。报告包含固定六部分：

  • 基本信息：实验名称、日期、姓名、学号、班级
  • 实验目的
  • 实验内容和要求
  • 实验结果（含关键步骤截图，每张图下写 1–2 句说明）
  • 实验中出现的问题汇总（问题、原因判断、解决方法）
  • 实验总结（3–5 句，说明学会了什么、哪里还不熟练）
截图范围：当前提示符 + 执行命令 + 输出结果。不要只截空桌面或无关窗口。截图必须清晰可读。
检查点：知道报告六部分分别要写什么，以及截图要包含哪些信息。

7. 学习方式与排错口诀

课堂原则：先照着教程做一遍，再自己重做一遍。报错时不要急着要答案，先看提示、看路径、查帮助。

常用自查命令
pwd          # 我现在在哪里
ls -la       # 这里有什么（含隐藏文件）
man 命令     # 查完整手册，按 q 退出
命令 --help  # 快速查看选项
clear        # 清屏
报错常见原因先做什么
No such file or directory路径或文件名写错pwd、ls 检查位置与拼写
command not found命令拼错或不存在检查大小写与拼写
Permission denied当前用户没有权限先确认操作，不要一看到就 sudo
Is a directory把目录当作普通文件操作ls -l 看对象类型
排错口诀：先看报错文字 → 再用 pwd 看位置 → 再用 ls 看内容 → 检查大小写和拼写 → 最后查帮助。
检查点：遇到报错时，能按口诀完成一次自查。
